# ToDoList

A simple, intuitive, and efficient to-do list application designed to help users organize tasks, manage their time, and stay productive. 
This app allows users to add, edit, delete, and mark tasks as complete. It also provides features for prioritizing tasks, setting due dates, and tracking progress.

## Features

1 Add new tasks with a title and description.
2 Mark tasks as complete.
3 Edit or delete existing tasks.
4 Set due dates and reminders.
5 Prioritize tasks by categories (optional).
6 Clean and user-friendly interface.
